# 運営手順

30テーマを監査済み。国家情報会議は公式政令附則により施行日を確認済み、個別保留なし。
問い合わせ・訂正はcontactページの専用Google Formsを使用。任意メール欄は返信希望時のみ。本文に個人情報を転載しない。誤りは一次情報を再確認し、訂正理由・日付を更新履歴に残す。定期的に窓口の到達と回答の確認を行う。
配信先はGitHub Pages。広告・独自解析・登録機能は未導入。外部サービスや機能変更時はPrivacyを実態に合わせて更新する。
mainへのpush前に全検証を通す。Actions完了後、実URLのトップ・記事・検索・運営導線を確認する。配信はdist/clientのみ。正本ローカルの管理資料や個人情報を追加しない。
