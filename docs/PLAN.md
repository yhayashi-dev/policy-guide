# 30テーマへの拡張（2026年9月10日）

既存構造を維持し、国会の議案経過と省庁の施行案内を優先して25テーマを追加。継続審査を独立した状態にし、成立済み・施行待ちとの重複を管理。対象の一覧はEXPANSION-30.md。

# 企画と実装判断

## 1. プロジェクト構成
既存のpaycheck-insightを変更しないため、独立したpolicy-guideフォルダを使用。記事・画面・検査・運用資料を分離する。

## 2. 技術
Sitesの標準雛形からReact 19 / TypeScript / Vinext / CSSを使用。静的書き出し後はHTML/CSS/JavaScriptのみで配信。複雑なバックエンドは不要。既存の部品と固定依存関係を維持し、配信時には使用した部分だけを含める。

## 3. データ
記事ID、分類、法律との関係、status、enacted、pending、本文の各項目、events（予定・確認済みを区別）、出典ID、publishedAt、updatedAt、checkedAt、reviewAfterを管理。statusは人が資料から確認した値。日付経過から推定しない。

## 4. 画面
紺色・白を基調にした読みやすい記事一覧。検索・状況・分類を組み合わせる。記事は13項目と出典への番号リンク。モバイルは一列と折りたたみ目次。ゼロ件、404、JavaScriptなしの閲覧を考慮。

## 5. 初版
年金制度改正、社会保険の加入対象拡大、高額療養費、在職老齢年金、国民年金の育児免除の5テーマ。年金の3記事は同じ法律である旨を明示する。選択的夫婦別姓の法務省ページは閲覧制限があり、直近の各法案の状況確認も必要なため初版では採用しなかった。消費税・皇室典範は追加調査対象として留めた。

## 6. 更新
一次情報の目視照合→JSON更新→自動検証→ビルド→確認→手動公開。検証は空欄、参照先、日付、不整合、リンクを対象とする。法的事実を機械的に認定しない。

## 7. 実装順と公開範囲
構成確認、一次情報調査、一覧・詳細、検索、静的書き出し、SEO、テスト、ブラウザ・リンク確認、Git差分確認、公開手順。ユーザーの「公開準備まで」に合わせ、リモートへの公開は未実施。

## 静的出力に関する判断
固定したVinext betaの静的書き出しでtrailingSlashやbasePathを直接指定すると、動的パスの事前生成でリダイレクト・404が発生した。ライブラリは改変せず、通常パスでHTMLを生成し、postbuildでdirectory/index.htmlへ配置する。BASE_PATHは画面リンクに明示し、生成されたアセットURLを配信階層に合わせて整える。実際の静的配信と検索後のリンクでサブディレクトリ運用を検証した。
